INVESTIGATION ONGOING…

LEAD 01 // TIME OBFUSCATION DETECTED

The Breakdown: Auditing the sale_date column revealed chaos. Three date formats: DD/MM/YYYY, YYYY-MM-DD, and raw Excel serial integers (like 44607).

The Sabotage Clue: 12,400 rows had quarter values that contradicted the actual transaction month (e.g. July = Q3 was tagged Q2).

The Solution: Constructed Excel formulas using DATE, LEFT, MID, and RIGHT to parse all formats, then derived clean quarter flags.

LEAD 02 // GEOGRAPHIC SPLIT DETECTED

The Breakdown: 6 standard regions were written in 14 different ways. North-West alone appeared as NW, North West, NORTH WEST, and north west. Region labels were randomly paired with all 21 states.

The Sabotage Clue: Splitting regions masks distributor performance. Sales totals get divided, preventing managers from spotting underperforming territories.

The Solution: Rebuilt using official Nigeria State → Geopolitical Zone lookup table with nested IFS and UPPER checks.

LEAD 03 // PROMOTIONAL BLIND SPOT

The Breakdown: Promo indicator was flooded with variants. Plus 13,094 rows left blank entirely.

The Sabotage Clue: Bypassing standardized promo flags allows hidden discounts to escape audit checks.

The Solution: Cleaned all promo variants using logical Excel sweeps, mapping everything to a strict binary 1 or 0.

LEAD 04 // MISSING EVIDENCE

The Breakdown: 19,045 rows lacked Total Revenue, 7,664 rows lacked Unit Price. Total sales volume heavily understated.

The Sabotage Clue: Blanks allow cash transactions to vanish. Impossible to balance bank sheets against inventory.

The Solution: Cross-referenced product SKUs against master price sheet to populate missing values mathematically.

LEAD 05 // THE DISAPPEARING NAIRA

The Breakdown: In 14,447 rows, recorded total_revenue did not equal units_sold × unit_price. Variance spanned millions.

The Sabotage Clue: Classic double-entry manipulation. Revenue formulas were overridden to misreport performance or cover inventory shrinkage.

The Solution: Automated Excel verification checks to isolate mismatches and compute true expected revenue.
