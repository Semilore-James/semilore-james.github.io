First-Time Setup

Do this once. Takes about 10 minutes.

01Create your GitHub repository

Go to github.com and sign in. Click the + in the top-right corner → New repository.

Name it exactly: semilore-james.github.io

Set it to Public. Leave everything else as default. Click Create repository.

The name matters. It must be your exact GitHub username followed by .github.io for GitHub Pages to work automatically. Any other name and you'd need extra configuration.
02Upload your files

On your new repository page, click uploading an existing file (the link in the middle of the empty repo page).

Drag and drop ALL files from your portfolio folder — the HTML files, all PNG images, and the work folder with its HTML files inside.

GitHub will preserve the folder structure. Scroll down, add a commit message like Initial portfolio upload, and click Commit changes.

For the work/ folder: GitHub's drag-and-drop uploader handles nested folders. Just drag the entire portfolio folder contents in one go.
03Enable GitHub Pages

In your repository, click Settings (top navigation tab).

In the left sidebar, scroll to Pages.

Under Source, select Deploy from a branch. Set the branch to main, folder to / (root). Click Save.

GitHub will show a message: "Your site is live at https://semilore-james.github.io". It takes 1–3 minutes to go live the first time.

04Verify everything works

Visit https://semilore-james.github.io and check:

✓  Homepage loads with all sections
✓  Images show (Moonframe screenshots, analytics screenshots)
✓  All nav links scroll correctly
✓  "See My Work" cards link to the right pages
✓  Case study pages load from the Work section
✓  "← Back to Portfolio" links on each page work

Images not showing? Check that your image filenames in the repository exactly match what's in the HTML. Filenames are case-sensitive on GitHub Pages even if they're not on your computer.

How to Update the Site

Every time you want to change something — add a project, update a case study, swap an image — the process is the same:

01Edit the file on your computer

Make your changes to the relevant HTML file. Save it. You can preview it locally by just opening the file in a browser — it'll look exactly as it will on the live site (except fonts may render slightly differently).

02Upload the updated file to GitHub

Go to your repository on github.com. Navigate to the file you edited (e.g. click into the work/ folder, then click moonframe.html).

Click the pencil icon (Edit this file) in the top-right of the file view. Paste your updated HTML. Scroll down, add a commit message describing what changed, and click Commit changes.

Alternatively — click the file, then click the three-dot menu → Upload files. Drag your updated file in. This is faster for binary files like images.

GitHub Pages re-deploys automatically within 1–2 minutes of any commit.

Adding a new project card (index.html)

Find the projects-grid div in index.html. Copy one of the existing project-card blocks and paste it after the last one. Update the href, image src, title, description, and tag text. The grid handles layout automatically — it's set to 2 columns on desktop, 1 on mobile.

Adding a new case study row (index.html)

Find the cases-wrap div. Copy one of the existing case-row blocks. Update the href, number, title, and subtitle. Then create the corresponding HTML file in the work/ folder — use any of the existing ones as a template.

Adding Your Power BI Dashboard

When your dashboard is ready

In Power BI Service, open your report. Click File → Embed report → Website or portal. Copy the embed URL (it looks like https://app.powerbi.com/reportEmbed?reportId=...).

Then find this section in index.html — search for POWERBI_PLACEHOLDER — and replace the placeholder block with:

<iframe
  src="YOUR_POWERBI_EMBED_URL_HERE"
  width="100%"
  height="480"
  frameborder="0"
  allowFullScreen="true"
  style="border:4px solid #000;box-shadow:6px 6px 0 #000">
</iframe>

That's the entire change. The styling is already set to match the portfolio's border treatment. Send me the embed URL and I'll make the exact edit for you.

Custom Domain (Optional)

If you ever want semilore.xyz or similar instead of semilore-james.github.io:

01Buy a domain

Namecheap, Cloudflare, or Google Domains are reliable. A .com or .xyz runs around $10–15/year.

02Point it to GitHub

In your domain's DNS settings, add a CNAME record pointing to semilore-james.github.io. Then in your repository Settings → Pages, add your custom domain. GitHub handles the HTTPS certificate automatically.

Deploy time after a commit

GitHub Pages usually rebuilds within 1–2 minutes. If you don't see your changes, do a hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).
